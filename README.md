# 倒立摆控制系统 — STM32 嵌入式调试日志

## 项目简介

个人项目 · 嵌入式控制 · 串级 PID

主控 STM32F103C8T6，TB6612 驱动直流电机，姿态传感器反馈角度，编码器反馈位置，实现摆杆稳定倒立。

本项目是一个完整的倒立摆控制系统，从外设驱动移植、标准库到HAL库移植、控制算法实现到参数整定全部独立完成。最终实现摆杆稳定倒立，并能在一定范围内进行调参优化。

## 项目状态

- ✅ 摆杆可稳定倒立，伴随轻微晃动
- ✅ 串级 PID（内环角度环 4ms，外环位置环 80ms）
- ✅ 不完全微分、微分先行、死区补偿均已验证
- ⚠️ 无法完全消除平衡点附近的微小抽动，已定位为机械死区与中心角度误差的耦合
- ✅ HAL 库全工程移植完成
- ❌ Z-N 法、Simulink/LQR 均已尝试，不适合本项目，已放弃并记录原因

## 硬件环境

| 部件 | 型号 |
| :--- | :--- |
| 主控 | STM32F103C8T6 |
| 电机驱动 | TB6612 |
| 姿态传感器 | 角度传感器（ADC） |
| 显示 | 0.96寸 OLED（软件 I2C） |
| 编码器 | 增量式编码器（TIM 编码器模式） |

## 关键量化数据

| 指标 | 数值 |
| :--- | :--- |
| 内环控制周期 | 4ms |
| 外环控制周期 | 80ms |
| 电机正向死区 | 10（PWM） |
| 电机反向死区 | 7（PWM） |
| Z-N 法临界增益 Ku | 0.62 |
| Z-N 法临界周期 Tu | ≈0.103s（17个周期平均） |
| 串口发送间隔优化 | 20-30ms → 1ms |
| 角度环参数 | Kp=0.350, Ki=0.006, Kd=0.307 |
